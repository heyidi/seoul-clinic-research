# Researching Korean Clinics

调研产出是**可核验的档案**,不是推荐意见。每个论断要么带来源,要么标"未获取"。

## 身份核验(必做,先于一切)

英文/中文社区名只是别名,必须解析出**韩文正名**并留证:

- 三方互证:官网 ↔ NAVER Place ↔ 官方社媒(域名互链,或地址+电话一致)。**社区帖子/博客提及不是互证的腿**,只能作辅助线索
- 记录:选定名+互证依据+**被排除的同名候选及排除理由**(如 다나의원/内科/中浪区 ≠ 단아의원/医美/明洞)
- 互证不满 3 腿 → verification_status=unverified,写明缺哪条腿;verified 只发给证据齐的档案

**`name_zh` 是显示名,不是备注栏。**(2026-09-02 实录:62 家里 33 家把说明塞进了这个字段,
最长 99 字,总览表的名字列因此撑成一堵墙。)格式固定为
**中文名(拉丁品牌)+ 机构类型 + 门店或地区**,例:`克林姆(Kleam)医院 明洞店`。

- **两个名都要写**。用户是拿着小红书/官网/中介给的名字来对号的,只留中文对不上英文品牌,
  只留英文对不上中文口碑贴——这是用户明确纠正过的一次(『克林姆和 Kleam 都应该写上』)。
- 没有既定中文译名的就用拉丁原名(Cellier / Brandnew / IEUML),**不要自己造音译**;
  已有译名一律沿用档案原值或既定对照表。
- **不放韩文**(有 `name_ko`),**不放解释性括号**。以下一律进 `notes` / `verification_notes`:
  被排除的同名候选、罗马化拼法沿革(ieuml/imeul)、英文自称的来历(Kleam=Korea+Gleam)、
  社区俗称、"勿与 XX 本店混淆"这类消歧提示。

## 记录契约(每行数据的必填槽位)

价格/评分/评论/资质,每条记录必须有:`source_url` + `collected_at`。`collected_at` 是**你实际采集/核对的当天日期**,不是发帖日、不是估计值——不知道就写"未获取",不许编日期。渠道穷尽后仍拿不到的字段,其值就是字面量 **"未获取"** —— 这是合法取值;推测值、第三方宣称都不能顶替。

## 医生资质判定(按可观察证据分档)

- 官网明载「X과 전문의」(带科目) → **specialist**,记科目
- 只写「전문의」无科目,或履历仅见 수련의/인턴(实习) → **unknown**,原文记录疑点
- 无专科表述 → **general**
- 厂商称号(Key Doctor/Ambassador)、学会 정회원、进修经历 → 记入荣誉/履历栏,**永远不构成资质档位的依据**
- 第三方文章的学历/专科宣称 → 单独 `unverified_claims` 栏(原文+出处),不并入资质

## 价格口径(按价签形态分流)

- **划线价陷阱(实录事故2026-07-16)**:韩国诊所价目页普遍"划线原价+实卖价"双数字,实卖价常仅为划线价一半;imweb 类建站工具会把实卖价放在 HTML 实体转义的数据块里,**必须先做实体+\uXXXX解码再解析**,并与浏览器渲染结果核对一遍。只见一个数字时要怀疑漏抓,price_krw 永远取实卖价,划线价进备注
- 价签用「+」连接多个项目 → **套餐**:不映射单项比价轴,原文构成进备注
- 划线价/이벤트/체험가 → `is_event=1`,并记正价与限制条件(VAT 별도、不可指定医生、首次限定)
- 金额保留**韩元原文**;结论中不做人民币/其他币换算(基线实测换算错 7 倍),让读者按当日汇率自算
- **解码零命中 ≠ 无价**:价目常整页做成长图(实录2026-07:两万像素活动长图含全套价目,静态解析必然零命中)。零命中后检查页内 `<img>`,把价目图下载归档并**视觉判读**,判读价的 spec_notes 注明"图片价目视觉判读"+图片归档路径;图上双数字同样按划线价陷阱处理,数字吃不准就不录

## 口碑分级(每帖必填性质标签)

小红书/社区每帖记录:原帖 URL + 性质 ∈ {官方号, KOC系列, 店家互动帖, 素人}。判定证据:IP 韩国+营销文案/店家回评/同作者探店系列 → 非素人。**未点名该诊所的帖子不入档**(通用教训可另立知识条目)。差评必须保留原文。

- **标题是钩子,作者是判据**:官方号惯用差评口吻标题引流(实录2026-07:诊所自营号发《求求你们不要再去do唇了😭》,置顶评论"预约找我")。见"避雷/差评/哭死"标题,先核作者——昵称含店名、与已知官方号名单对照、有无店家式回评;判为官方号/店家帖的,情绪化标题按营销内容处理:性质如实写,sentiment 标中性,不计入差评
- **证据面 = 正文 + 评论区**:高价值素人差评常藏在提问帖评论区(实录2026-07:"毁容"控诉全在评论,正文只有一句提问)。正文空洞先逐条过评论再定弃留;评论区证据入档时注明"(评论区)"并保留原文

## 结论的形状

结论 = ①已证实清单 ②风险点(逐条) ③待现场核实项。证据不足时结论就是"证据不足+核实清单"。担保性措辞("放心预约""没有红旗""值得信赖")不属于调研结论的词汇表。

## 常见冲动 → 现实

| 冲动 | 现实 |
|---|---|
| "用户着急,给个痛快结论" | 快≠担保。缺证据时,痛快的结论就是核实清单 |
| "官网写了전문의,那就是专科医" | 无科目无法验证,档位是 unknown |
| "Merz 认证侧面说明有正规培训" | 厂商市场合作身份,写荣誉栏 |
| "IP 韩国的帖子也是正面口碑" | 官方号软广,性质标签必填 |
| "顺手换算成人民币方便用户" | 保留韩元。换算错一位数比不换算伤害大 |
